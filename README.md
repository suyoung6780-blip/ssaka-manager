# 싸카매니저 (SSAKA MANAGER)

축구팀 매니지먼트 웹앱. Firebase(로그인·DB·파일·서버 함수) + 토스페이먼츠(팀 월 이용권 결제).

> **지금은 무료 운영 모드**(`js/config.js` 의 `FREE_MODE = true`)입니다. 결제 없이 지도자가 팀을 만들면 바로
> 10자리 팀 코드(대문자·소문자·숫자 섞음, 대소문자 구분, 매번 새로 생성)가 발급됩니다. Cloud Functions 없이 동작합니다.
> 유료로 바꿀 때는 `FREE_MODE = false` + `firestore.rules` 의 '무료 모드' 줄 삭제 + Functions 배포.

## 배포 (지금 쓰는 방법 · 무료)

1. GitHub 에 저장소 `ssaka-manager`(공개)를 만들고 이 폴더의 파일을 올립니다 (웹에서 끌어다 놓기).
2. Vercel → Add New → Project → `ssaka-manager` 가져오기 → Deploy. 설정은 `vercel.json` 에 들어 있음
   (화면 파일 = `public/`, 축구 브리핑 = `api/feeds.py` 서버 함수, 30분마다 새로 모음).
3. Firebase 프로젝트를 만들고 `public/js/config.js` 의 `firebaseConfig` 를 채운 뒤 다시 올리면 로그인 · 저장이 됩니다.

## 처음 설정하기

### 1. 준비물
- [Node.js 20 LTS](https://nodejs.org) 설치 → 터미널에서 `npm install -g firebase-tools`
- `firebase login`

### 2. Firebase 프로젝트
1. https://console.firebase.google.com → 프로젝트 만들기
2. **요금제를 Blaze(종량제)로 변경** — Cloud Functions · Storage 사용에 필요 (소규모는 무료 한도 안)
3. Authentication → 로그인 방법 → **이메일/비밀번호** 사용 설정
   - 운영자: `public/js/config.js` 의 `ADMIN_EMAILS` · `firestore.rules` 의 `isAdmin()` 이메일로 가입 → 메뉴 '운영자 인증'에서 이메일 인증하면 전체 공지 · 전체 팀 메뉴가 열림
   - Authentication → 템플릿 → 비밀번호 재설정 → 수정: 보낸사람 이름 '싸카매니저', 언어 한국어,
     **작업 URL 맞춤설정**을 사이트 주소(예: `https://<프로젝트>.web.app/`)로 → 메일 링크가 앱 안의 '새 비밀번호 정하기' 화면으로 열림
4. Firestore Database → 데이터베이스 만들기 (위치: `asia-northeast3` 서울)
5. Storage → 시작하기
6. 프로젝트 설정 → 내 앱 → 웹 앱 추가 → 나오는 `firebaseConfig` 값을 **`public/js/config.js`** 에 붙여넣기
7. **`.firebaserc`** 의 `YOUR_PROJECT` 를 프로젝트 ID 로 변경

### 3. 토스페이먼츠
- 테스트: `config.js` 에 문서용 테스트 클라이언트 키가 들어 있습니다. 짝이 되는 시크릿 키를 서버에 등록:
  ```
  firebase functions:secrets:set TOSS_SECRET_KEY
  # 입력값: test_sk_zXLkKEypNArWmo50nX3lmeaxYG5R
  ```
  (안 되면 https://developers.tosspayments.com 가입 후 내 테스트 키 사용)
- 실제 결제: 사업자등록 → 토스페이먼츠 가맹 계약 → 라이브 키(`live_ck_…` / `live_sk_…`)로 교체
- 요금 변경: `public/js/config.js` 의 `PLAN.price` 와 `functions/index.js` 의 `PLAN_PRICE` 를 **같이** 수정

### 3-1. 분석실 영상 (Storage CORS)
분석실의 트래킹 · 크로마키는 브라우저가 영상 픽셀을 읽어야 해서, Storage 버킷에 CORS 설정이 한 번 필요합니다.
```
gsutil cors set storage-cors.json gs://<프로젝트>.appspot.com
```
(Google Cloud SDK 의 gsutil 사용. 안 하면 영상은 재생되지만 트래킹·크로마키가 꺼집니다.)
분석 영상은 코치만, 1GB 이하 동영상만 올릴 수 있습니다 (storage.rules).

### 4. 배포
```
cd functions && npm install && cd ..
firebase deploy
```
배포가 끝나면 나오는 `https://<프로젝트>.web.app` 주소로 접속합니다.

## 사용 흐름
1. 코치: 회원가입 → 개인계정(코치) → 팀계정 만들기 → (무료 모드: 바로 / 유료: 결제 후) **팀 코드 발급** (팀 설정 · 락커룸에서 확인)
2. 선수: 회원가입 → 개인계정(선수) → 팀 코드 입력 → 락커룸 입장
3. 팀 공개 설정: 공개면 다른 팀이 오른쪽 팀 검색에서 선수단·프로필을 볼 수 있고, 바로 위 연령 팀 코치는 찜 가능(상대는 모름). 연락은 팀 계정끼리만, 비공개면 팀 이름만 보임

## 분석실 (영상 분석)
- 영상 업로드 → 스튜디오에서 그림. 모든 처리는 브라우저에서 (서버 비용 없음)
- 트래킹: 선수를 누르면 몸(잔디 아닌 덩어리)을 찾아 발밑 · 키를 자동 측정 → 재생하면
  카메라 패닝 보정 + 속도 예측 + 유니폼 색 분포(상의/하의)로 원본 해상도에서 따라감.
  화면이 크게 바뀌어도(카메라 급회전 · 편집 컷) 멈추지 않고 더 넓게 다시 찾아 계속 따라감
- 트래킹: 선수를 네모로 감싸서(또는 클릭) 시작. 멈춰 있을 때 네모를 옮기거나 모서리를 끌어 선수에 맞추면 그 장면부터 다시 익혀서 따라감. 발밑 원 · 머리 위 ▼ (선수 키에 맞춰 크기 자동), 이름표 선택
- 표시 규칙: 모든 그림은 나타나는 장면에서 4초 멈춤(그림마다 수정). 트래킹 · 연결선은 멈춘 뒤 '따라가는 시간'(기본 5초, 수정) 동안 선수를 따라가고, 나머지 그림은 멈춘 동안만 보이고 재생되면 사라짐
- 도형: 동그라미 · 세모 · 네모 · 오각형 · 육각형을 바닥에 눕힌 모양으로, 꼭짓점을 끌어 모양 변경 (동그라미는 상하좌우 점으로 크기만 바뀌고 항상 타원 유지)
- 색: 노랑 · 빨강 · 흰색 · 하늘 · 초록 · 투명(반투명 흰색)
- 화면: 영상은 브라우저가 원본 화질로 직접 재생하고 그림만 위에 겹침, 재생 중 분석은 따라갈 선수 · 바닥 그림이 있을 때만 → 끊김 없음. 내보내기는 원본 해상도(최대 1920px) · 16Mbps
- '선택' 버튼 없음: 어떤 도구를 쓰는 중이어도 그림을 누르면 바로 끌어 옮김 (그리기 도구일 때 그리드 · 영역 안쪽과 선수 발밑은 새로 그리기가 우선). 도구는 한 번 그리면 자동 해제, 다시 누르거나 Esc 로도 해제
- 선수 근처에서 시작한 화살표 · 영역은 그 선수에 붙음
- 화살표 · 이동 점선은 바닥에 깔린 두꺼운 리본(원근 · 그림자 · 광택), 1.6초에 걸쳐 그어지면서 (연결선은 바로 나타남)(그림마다 '그어지는 시간' 조절), 영역 · 그리드 · 원은 서서히 나타남
- 그리드: 바닥 범위를 끌면 원근(잔디 시작선 기준) 사다리꼴로 깔리는 체크무늬 그리드
- 연결선: 누른 선수는 자동으로 트래킹되고 발밑 원끼리 이어짐
- 선수 이동: 선수를 누른 채 끌면 오려낸 선수가 새 자리로 이동하는 효과, 원래 자리는 어둡게 남음
- 거리: 그리면 m 값을 직접 입력 (화살표에도 m 표시 가능)
- 도구를 누르면 영상이 자동으로 멈춤
- 그림마다 표시 시간(초)과 '나올 때 멈춤'(초) 설정 → 재생 중 그 장면에서 멈췄다가 이어서 재생 (내보내기 영상에도 반영). 트래킹은 표시 시간 동안만 따라감
- 크로마키: 잔디색(영상 열 때 자동 인식) 위에만 그림이 보여서 선수가 그림 앞에 서 있는 것처럼 보임
- 그리드에 실제 크기(m)를 넣으면 거리 입력 칸에 자동 계산값이 미리 들어감
- 영역 · 연결선 · 화살표의 점을 트래킹 선수 근처에 찍으면 선수에 붙어서 같이 움직임
- 영상으로 내보내기(webm 녹화)
- YouTube 링크는 재생 + 타임라인 메모만 가능 (픽셀 접근 불가)

## 오늘의 축구 브리핑
- 뉴스: 언론사가 공개한 RSS(인터풋볼 · 풋볼리스트 · 베스트일레븐 · 스포탈코리아 · 연합뉴스 · BBC · Sky Sports · Guardian)에서 **제목과 링크만** 보여주고 원문은 언론사 사이트에서 열립니다.
  구글 뉴스 RSS 는 약관상 비상업적 용도만 허용돼서 쓰지 않습니다. 정식 유료 서비스 전에는 각 언론사 RSS 이용약관을 확인하거나 네이버 검색 API(무료, 약관상 서비스 사용 가능)로 바꾸는 것을 권장합니다.
- 유튜브: 채널 공개 RSS + 공식 임베드 플레이어 (API 키 불필요)
- 인스타그램: 공식 프로필 임베드. 계정 추가/삭제는 브라우저마다 저장됩니다.
- 출처 추가: `functions/feed-sources.json` 수정 (유튜브는 채널 ID `UC…` 필요)
- 서버는 10분마다 새로 수집합니다.

## 참고
- 월 이용권은 **30일 단건 결제 후 연장** 방식입니다. 매달 자동 청구(정기결제)는 토스 자동결제(빌링) 별도 계약 후 추가할 수 있습니다.
- 프로필 사진은 흑백으로 변환·축소되어 저장됩니다.
